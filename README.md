# InventoryPro — Inventory Management System

A professional, responsive Inventory Management System built using **HTML, CSS and vanilla JavaScript**.

## Features
- Dashboard with inventory KPIs
- Inventory health visualization
- Product CRUD (add, edit, delete)
- Search and category/status filtering
- Stock-in and stock-out management
- Stock movement history
- Inventory analytics and category reports
- CSV export
- Print-friendly report
- Dark mode
- Responsive design for desktop, tablet and mobile
- LocalStorage persistence — no backend required
- Login and sign-up authentication gate
- Protected inventory workspace (locked before authentication)
- User profile view/edit
- Logout from header/sidebar/profile

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. No installation or server is required.

For best development workflow, you can also open the folder in VS Code and use the Live Server extension.

## Project structure
- `index.html` — application structure and UI
- `style.css` — complete responsive styling
- `script.js` — inventory logic, CRUD, filters, reports and LocalStorage
