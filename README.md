# Inventory Management System

Basic internship project built with **HTML, CSS and JavaScript**.

### Features
- Inventory tracking
- Add, edit and delete products
- Stock In / Stock Out
- Search and filtering
- Low-stock and out-of-stock detection
- Inventory value calculation
- Reports dashboard
- Category-wise stock report
- Stock movement history
- CSV export
- Unique SKU validation
- Prevents negative stock
- Responsive UI
- localStorage persistence

### Run
Open the folder in VS Code and open `index.html` with Live Server, or open it directly in a browser. No Node.js or database is required.

### Project structure
`index.html` — structure and pages
`css/style.css` — responsive professional styling
`js/app.js` — CRUD, validation, stock logic, reports and localStorage

### Interview explanation
I developed a responsive Inventory Management System using HTML, CSS and JavaScript. It supports product CRUD operations, stock-in and stock-out transactions, search and filtering, low-stock alerts, inventory valuation, category reports and CSV export. I used localStorage for browser-side persistence and JavaScript validation to maintain accurate inventory data.
